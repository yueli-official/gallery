# 图片特征

Gallery 以人物图为主。“图片特征”（`image-features`）是一个可选、多选的 Facet，与“作品与角色”并列。内部六组只负责组织目录：

| 分组 | 内容 |
| --- | --- |
| 人物外观 | 人数、发色、发型、形象特征 |
| 服饰装扮 | 服装、配饰 |
| 动作表情 | 姿势动作、表情 |
| 画面构图 | 景别、视角 |
| 场景背景 | 场景、背景类型 |
| 表现形式 | 画面形式、绘制风格、色彩 |

首批115个具体特征在迁移 `0025_image_features` 中定义。后续增删、改名、归属和启停使用现有 Classification 管理接口；迁移不对已有图片或标签作推断和批量赋值。

## 赋值与查询

- 只赋具体叶值；目录标题不可勾选。整个维度0–32项，共享 Classification 策略 `leafOnly=true` 负责服务端校验。
- 发色允许多个，例如白发、粉发、渐变发色同时存在；Q版、黑白、多格漫画也可以组合。看不清或不适用的特征留空。
- 景别、视角和姿势分开，全身、背面、坐姿可以同时成立。人数指画面主体，复杂漫画不强制填写。
- 白色背景是视觉特征，透明背景需要实际透明背景依据，不能仅凭白底或存在少量半透明像素判断。
- `facets=image-features:white-hair,image-features:school-uniform` 表示同时满足。`matchAll` 继续控制其他维度的多值语义，不改变图片特征的合取；Facet UUID/compact ID 和值身份仍由共享 Classification 解析。
- 特征候选数量保留已经选择的全部特征条件，表示继续组合后的图片数；其他维度保持原有候选计数语义。

## 界面与投稿

公开筛选、网站单张/批量投稿和图片后台编辑共用 `GalleryFeatureChoices`：默认收起，展开后显示分组，可搜索目录路径或具体特征；已选项可直接移除。油猴1.5.0提供同样的分组、搜索和摘要，只有具体值进入既有 `facets[].valueIds`。后台发布队列仍固定入队时的完整元信息快照。

网站及脚本沿用已有投稿/上传合同，无新增HTTP DTO。后台编辑改为共享分类策略验证多值和叶值，并在事务内锁定校验目录revision，避免继续使用“每维度仅一个值”的旧产品限制。

迁移在现有目录上直接增加维度；空数据库先完成schema migrations，再由bootstrap调用同一个数据库种子函数。重复bootstrap保留运营修改。上线须部署API与Web并应用0025迁移；本地源码或脚本更新不等于线上目录已经创建。

未来提示词映射和原始生成参数属于后续独立能力，本次没有自动识图、生成提示词或原始参数提取。
