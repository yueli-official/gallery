# 资源引用与图片发布

资源策略使用公共 AssetPolicyPage，包含用途、资源引用、筛选、任务记录和两个全局同步入口。刷新只读取状态；同步未同步对象处理整个空间未确认的意图，强制同步全部重投已登记意图，均不受列表筛选影响。

## 新建与引用

上传Finalize携带临时draftSessionId，投稿队列和分类视觉编辑器显示期限及重新开始操作。保存后，投稿、图片、分类和站点背景各有业务对象完整引用，业务SQL与任务同事务；后台确认前仍由持久预留保护。关闭编辑器不直接删文件。

审核提交后不等待公开派生图RPC；图片只有在后台引用投递及公开发布成功后才可公开。AfterApply重读并锁定当前图片，失败在同一任务重试。导入替换原图会记录待撤销旧公开能力，跟随同一图片任务完成。

## 解引用与下架

撤稿清空该投稿引用；已发布图片隐藏后原图仍由图片对象保留，公开展示能力撤销。删除图片同时清空图片及所有关联投稿引用，并持久撤销公开规格。分类/背景被替换或移除只解除对应使用关系，不直接删除素材。同图还有其他对象、临时草稿或Asset公开能力时继续受保护。

## 首次迁移与校准

先应用0018–0022迁移，停止旧快照及发布扫描Worker，再以相同运行环境执行：

```powershell
go run ./cmd/asset-references -initialize -actor operator:your-name
```

初始化显式枚举所有当前对象，包括已删除图片的空集合，补齐公开能力撤销任务。API启动不执行全站扫描。历史初始化与日常强制同步用途不同；绕过DAO的导入须同时接入事务Module，不能靠刷新修复。

当前为未发布源码候选，注册complete=false；迁移、Go及PG验证不等于正式制品/浏览器/线上验收。
